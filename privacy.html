プライバシーポリシー

対象：event-prep-planner ／ 制定日：2026年11月10日

event-prep-planner（以下「本アプリ」）は、開発者本人が自分の Google アカウントで使うための個人用アプリです。本アプリが取得する情報と、その扱いを以下に定めます。

1. 取得する情報

  • Google カレンダー（読み取りのみ）：予定のタイトル、日時、場所、説明。権限は calendar.readonly で、カレンダーへの書き込みは行いません。
  • Google ToDo リスト：本アプリが作成するリストのタスク（タイトル、期限、メモ、完了状態）。重複の防止と、予定の変更への追従のために読み書きします。

2. 利用目的

取得した情報は、予定に向けた準備の Todo を作成し、Google ToDo リストに登録・更新するためだけに使います。広告、分析、その他の目的には使いません。

3. 外部サービスへの送信

準備の Todo を作るため、予定のタイトル・日付・場所・説明を、AI サービス（Anthropic 社の Claude API）に送信します。送信するのは Todo の作成に必要な範囲に限ります。

4. 保存する情報

  • 処理の状態を管理するため、予定とタスクの識別子、予定の開始日、タスクの期限などを、開発者が管理するクラウド（AWS）に保存します。予定やタスクのタイトルなどの内容は保存しません。
  • 保存した情報は、予定の日から30日後に自動で削除します。
  • 動作記録（ログ）には、件数や識別子のみを記録し、予定の内容は記録しません。

5. 第三者への提供

取得した情報を販売したり、第三者に提供したりすることはありません（上記3の Todo 作成のための送信を除きます）。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

7. アクセス権の取り消し

本アプリへのアクセス権は、Google アカウントの「サードパーティのアプリとサービス」からいつでも取り消せます。

8. 改定

本ポリシーを改定した場合は、このページで公開します。

English summary

event-prep-planner is a personal app used only by its developer. It reads Google Calendar events (read-only, calendar.readonly) and reads/writes tasks in a dedicated Google Tasks list (tasks) solely to create and update preparation to-dos. Event titles, dates, locations and descriptions are sent to Anthropic's Claude API only to generate those to-dos. Only identifiers and dates (not event or task contents) are stored on AWS, and they are deleted 30 days after the event. Data is never sold or shared for any other purpose. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from your Google Account permissions.
